# Workflow Baseline

- Identify the requested outcome, authorized scope, and stop condition.
- Separate confirmed evidence from assumptions and recommendations.
- Use read-only evidence before proposing production changes.
- Explain technical points in plain language when the task calls for it.
- Report capability gaps and unverified results explicitly.
